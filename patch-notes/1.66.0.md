# v1.66.0: Codex, saves, offline and tooling

**Codex:** counter towers on every foe, ground/air/ships filter, a glossary. **Profile:** best in each mode. **Saves:** download as a file; checksum warns on a changed export, old exports still import.
**Orders:** six new daily order types from 2026-11-10.
**Offline:** the game shell is cached (network first), a calm update note appears outside runs, an error screen keeps progress safe, the Realm lists what is unavailable offline.
**Tooling:** `npm run check`, content-integrity and determinism tests. Two `Math.random` calls in engine code are now seeded.
**Unchanged on purpose:** ranked boards and scoring. The attack-mode cooldown fix only changes the first-shot timing of an emplacement.

See IMPROVEMENTS.md for the list.
