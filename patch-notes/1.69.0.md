# v1.69.0: The Season Road

**New:** the Season Road, a reward road that starts again every month. Every run in every mode earns Season XP.
**New modes:** Sudden Death (the first foe through the gate ends the run) and Boonstorm (a boon after every wave).
**Feats:** nine new achievements for the Season Road and both modes.
**Phones:** the screen stays awake in a battle, Back steps out of a screen instead of the game, add to home screen from the Today card, damage numbers no longer pile up.
**Fixed:** a run could lock up when every boon was at its limit; Escape closed every open dialog at once.
**Unchanged on purpose:** every existing mode, the leaderboards and the server.

See IMPROVEMENTS.md for the list.
